TERMINAL CASINO ROGUELIKE — v2.1.223

КРИТИЧЕСКИЙ HOTFIX: ЗАВИСАНИЕ ПОСЛЕ БОССА

- Исправлена воспроизводимая блокировка после последовательности «выбор контракта → приз босса → ставка» на поздних циклах, в том числе у Живого казино.
- Причина: после приза босса INSTALL мог начать бессрочно ждать решение по ставке, хотя карточка ставки не оказалась на экране. Игровая фаза уже блокировала движение, но видимого окна не оставалось.
- Карточка ставки теперь позиционируется только относительно действительно открытого INSTALL. Закрывающаяся анимация окна приза босса больше не может вытолкнуть следующую карточку за экран.
- Если справа недостаточно места, ставка автоматически ставится слева от INSTALL; без действующего INSTALL она гарантированно появляется по центру.
- Добавлено подтверждение фактической видимости карточки. Обычная видимая ставка по-прежнему не имеет таймера и ждёт явного «ПРИНЯТЬ» или «ПРОПУСТИТЬ».
- Если карточка по технической причине вообще не появилась на экране, необязательная ставка безопасно пропускается и переход в следующий сектор продолжается. Невидимый UI больше не способен уничтожить забег.
- Защита работает одинаково в одиночной игре, у хоста и у подключённого игрока.

ПРОВЕРКА

- Добавлен регрессионный прогон конца третьего цикла именно за Живое казино.
- Проверена очередь: выбор контракта → все допустимые типы приза босса → ставка → следующий сектор.
- Отдельно проверены два режима: видимая ставка остаётся без таймера; невидимая ставка освобождает зависший переход.
