# v2.1.201 — Static Strike / INSTALL Storm Clarity

## STATIC STRIKE

- Базовый радиус уменьшен ровно в 1,5 раза.
- Усиления следующих уровней по-прежнему увеличивают диаметр.
- Попадание теперь использует отдельную точную проверку пересечения круга удара с корпусом врага.
- Враг, касающийся границы зоны, получает урон; враг полностью за границей — нет.
- Враги в фазе появления по-прежнему защищены от урона.
- После удара больше не остаётся залитая область: только короткая вспышка разряда.
- Описание обновлено на русском и английском.

## BLACK BOX

- Улучшения теперь уменьшают радиус обнаружения вместо его увеличения.
- Первый уровень сохраняет большую базовую зону, второй и третий последовательно сжимают её.
- Длительность по-прежнему растёт.
- Описания и список эффектов улучшения обновлены на русском и английском.

## STATIC STORM / INSTALL

- Настоящий случайный модификатор `STATIC STORM` отделён от шторма, полученного через CRS, казино, перенос и `STATIC CORE`.
- Технический шторм от долга или ядра больше не выдаётся в интерфейсе за модификатор комнаты.
- Слева в INSTALL появился отдельный прогноз общего уровня шторма и его источников.
- Для босса и комнаты отдыха накопленный статик показывается как запас, ожидающий следующий боевой сектор.
- `STATIC CORE` в недопустимом секторе явно помечается как временно приостановленный.
- Источники накопленного шторма сохраняются в прогнозе, даже если ближайшая комната не может активировать его.

## Проверки

- Граница попадания STATIC STRIKE: внутри, ровно на краю и снаружи.
- Защита врагов в фазе появления.
- Уменьшение радиуса BLACK BOX с каждым уровнем.
- Разделение природного модификатора, CRS-долга и STATIC CORE в снимке комнаты.
- Сохранение накопленного шторма перед боссом.
- RU/EN-тексты, клиентский эффект и стили INSTALL.
