# TERMINAL CASINO ROGUELIKE — v2.1.194

## ИСТОЧНИКИ СТАТИК-ДОЛГА

Статик-долг теперь появляется только из явных событий:

- открытие проклятого сундука `CRS`;
- результат `STC` в терминале казино;
- видимый долговой результат ролла мутации `CASINO`;
- естественный модификатор сектора `STATIC STORM` и его перенос от реальных попаданий;
- результат статик-шторма внутри модификатора `CASINO VIRUS`.

## ИСПРАВЛЕНО

- `STATIC PULSE` больше никогда не создаёт статик-долг сама по себе.
- Другие Q без видимого казино-ролла также не создают долг.
- `BAD TAPE + CASINO` больше не выдаёт скрытый долг: опасный исход запускает полноценный видимый казино-ролл.
- Провал бонусной ставки контракта больше не добавляет скрытый статик-долг.
- `STATIC CORE` сохраняет урон и удачу, но больше не возрождает шторм автоматически в каждом боевом секторе.
- Приз контракта `CLEAR STATIC STORM` теперь снимает весь накопленный долг и весь перенос с прошлого сектора, а не один уровень.
- Новый шторм после очистки может появиться только от нового разрешённого источника.

## ПРОВЕРКА

- Проверены все места записи статик-долга в симуляции.
- Проверены отдельные сценарии `STATIC PULSE`, мутации `CASINO`, полной очистки контракта, `STATIC CORE` и естественного модификатора.
- Пройдены все автоматические проверки v2.1.181–v2.1.194.
- Проверены тексты RU/EN.
