# v2.1.185 — Boss / Casino / Gold Fever audit

## Casino Mob

- Базовый запас HP уменьшен примерно вдвое: `6120 → 3060`.
- Фазы одного Казино-моба больше не повторяются. История фаз сохраняется между всеми тремя сборками тела.
- При первом падении ниже 50% HP за весь бой Казино-моб один раз вызывает небольшую волну — до трёх быстрых базовых противников с учётом лимита комнаты.

## Боссы

- С начала боя каждый основной босс постепенно добавляет фоновое давление: по одному обычному `GRUNT` или `RUNNER` за раз.
- Это отдельный дополнительный слой. Существующие атаки, уникальные призывы и старые пачки противников после потери HP не заменены и не изменены.
- Фрагменты Хора охотников не создают собственные параллельные потоки призыва.

## Золотая лихорадка

- Вампиризм в секторе `GOLD FEVER` теперь возвращает кредиты вместо HP.
- В обычных секторах вампиризм по-прежнему лечит.
- Подсказка правила обновлена на русском и английском.

## INSTALL UI

- Повторно проверена карточка следующего сектора слева от окна INSTALL.
- Модификаторы следующего сектора отображаются всегда; блок контракта появляется только тогда, когда контракт действительно есть.
- Добавлена регрессионная проверка разметки, положения карточки и RU/EN-текста.
