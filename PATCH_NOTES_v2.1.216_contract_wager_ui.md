# v2.1.216 — CONTRACT / WAGER UI

- Контрактный WPN/ABL-приз теперь открывает отдельный бесплатный выбор из четырёх улучшенных вариантов до обычного INSTALL.
- На контрактный выбор даются отдельные 30 секунд; после него продолжается обычная очередь INSTALL.
- Таймер обычного INSTALL увеличен вдвое: до 96 секунд. Сигнатурный приз босса сохранил собственные 64 секунды.
- Wager больше не имеет таймера. При открытом INSTALL он стоит строго справа и выровнен по верхнему краю; без INSTALL занимает центральное место.
- Выполненный Wager сразу зеленеет и подтверждается отдельным звуком. Его награда включается только с начала следующего сектора.
- Добавлены подробные RU/EN-подсказки для всех контрактных призов, включая карточки выбора контракта.
- Для входа в боссовый Q-сайленс и выхода из него добавлены разные звуки и подтверждение восстановления Q.
- Убран лишний прямоугольный текстовый блок из верхней части полноэкранного визуала сайленса; остались рамка и помехи.
- Проведена проверка одновременных окон, таймеров, скрытия пустых блоков и локализаций.
