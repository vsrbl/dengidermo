# v2.1.189 — Reroll Charge Sync Hotfix

## Переброс выбора

- Исправлено исчезновение второго переброса после использования первого.
- Локальный интерфейс больше не вычитает уже подтверждённый сервером заряд повторно.
- Пока подтверждение ещё не пришло, использованный заряд по-прежнему скрывается сразу и не появляется обратно из устаревшего состояния.
- После подтверждения серверного остатка кнопка показывает точное число доступных перебросов.
- Серверная механика не изменена: один переброс расходует ровно один заряд.

## Область действия

- Переброс остаётся доступен для WPN-сундуков, ABL-сундуков и выбора награды босса.
- RAR и обычный INSTALL по-прежнему не используют этот приз контракта.

## Проверки

- Проверен сценарий: два заряда → использован один → сервер показывает один → кнопка второго переброса остаётся.
- Проверены два быстрых переброса до прихода серверного состояния.
- Проверено серверное списание ровно одного заряда и правильный остаток в сетевом снимке.
