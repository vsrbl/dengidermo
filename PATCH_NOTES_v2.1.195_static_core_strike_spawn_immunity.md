# v2.1.195 — STATIC CORE / STATIC STRIKE / SPAWN IMMUNITY

## Главное

- `STATIC CORE` снова создаёт статик-шторм в каждом подходящем боевом секторе.
- Награда контракта очищения снимает накопленный статик-долг и навсегда глушит шторм от `STATIC CORE` на текущий забег.
- После очищения новые явные источники статик-долга по-прежнему работают: проклятый сундук, казино и модификаторы комнаты.

## Новая Q-активка — STATIC STRIKE / СТАТИК-УДАР

- Добавлена в пул сундука протоколов (`ABL`).
- Q помечает точку курсора без отдельного режима установки.
- Перед ударом появляется обычная предупреждающая зона и проходит короткая задержка.
- Союзный шторм заметно светлее обычного: светло-голубые предупреждение и удар.
- Удар наносит урон только врагам. Игроки и подконтрольные процессы не получают урон.
- У активки есть отдельные звуки постановки предупреждения, запуска Q и самого статик-удара.
- Каждый уровень одновременно:
  - повышает урон;
  - сокращает базовое восстановление;
  - увеличивает диаметр удара.

## Защита появления врагов

- Подтверждён и исправлен баг, позволявший некоторым обходным источникам задеть врага внутри зоны появления.
- Пока идёт предупреждение появления, враг теперь не получает:
  - урон по HP или броне;
  - оружейные статусы и цепной урон;
  - урон и контроль от Q, рывка и полей;
  - притяжение, отбрасывание и замедление;
  - воздействие модификаторов комнаты и подконтрольных процессов.
- После завершения таймера появления все взаимодействия включаются как обычно.

## UI / локализация

- Добавлены короткие RU/EN-названия и описания `STATIC STRIKE`.
- В источниках шторма снова отображается `STATIC CORE / статик-ядро`.
- Обновлены версия, загрузочные метки и cache-busting до `v2.1.195`.
