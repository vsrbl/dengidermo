# v2.1.212 — Boss Silence Signal / UI & Cursor Fix

## Сайленс боссов

- Пока босс блокирует Q, на всём экране работает отдельный фиолетовый сигнал помехи.
- Добавлены движущийся скан, экранная рамка, угловые метки, короткие цифровые разрывы и компактный таймер.
- При первом наложении сайленса возникает усиленный стартовый импульс; затем эффект становится спокойнее и не закрывает врагов и снаряды.
- Эффект читает настоящий таймер дебафа и полностью исчезает вместе с ним.
- Тексты проверены на русском и английском.
- В тестовую панель добавлена кнопка `Q SILENCE 30s` для повторной визуальной проверки.

## Левый блок INSTALL

- Если у следующей комнаты нет модификаторов, контракта и Static Storm-информации, левый контейнер полностью скрывается и очищается.
- Высота блока теперь всегда определяется фактическим содержимым: без фиксированной или минимальной пустой области.

## Мышь и курсор

- Убран поток `pointerrawupdate`, который мог отправлять сотни лишних обновлений DOM между кадрами.
- Курсор теперь напрямую следует за браузерным `pointermove`, без дополнительного кадра задержки.
- Смена видимости и режима курсора больше не пересчитывает CSS-классы при каждом движении.
- Подсказки больше не вызывают `elementFromPoint` и принудительный пересчёт размеров страницы на каждом движении мыши.
- Позиционирование подсказки ограничено одним обновлением за кадр, а её размер измеряется только при смене содержимого.
- У карточек сундуков, INSTALL, контрактов и кнопок убрана задержка hover-анимации.
