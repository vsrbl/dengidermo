# v2.1.215 — INSTALL Intel / Anchor Phase Signal

## Левый блок INSTALL

- Исправлена причина пустого блока: содержимое больше не пересоздаётся каждый кадр и не застревает на первом прозрачном кадре анимации.
- Блок перестраивается только при реальном изменении следующей комнаты, модификаторов, Static Storm или выбора контракта.
- Добавлен запасной источник данных выбора контрактов на момент перехода между сетевыми снимками, чтобы реальный контракт не считался пустым.
- При переключении RU/EN содержимое немедленно перестраивается на выбранном языке.
- При отсутствии данных контейнер полностью очищается и скрывается; пустая рамка дополнительно блокируется стилями.
- При закрытии INSTALL старые данные немедленно удаляются.

## Босс ANC+ с полем

- При включении поля появляется крупный фиолетовый разворачивающийся квадратный импульс и надпись `ПОЛЕ ВКЛЮЧЕНО`.
- При отключении поля квадрат сжимается голубым сигналом и появляется надпись `ПОЛЕ ОТКЛЮЧЕНО`.
- Для включения и отключения созданы разные звуки: тяжёлый набор поля и короткий спадающий сигнал открытия огневой фазы.
- Боевая схема не менялась: 10 секунд поле и статик-пульсы, затем 5 секунд только стрельба.

## STATIC CORE

- Каждый уровень умножает весь исходящий урон на `1.35`, даёт `+2` удачи и добавляет один уровень Static Storm от ядра.
- Шторм ядра действует в боевых секторах и у боссов, но не в безопасной комнате отдыха.
- Шторм ядра сам по себе не переносит дополнительные уровни в следующую комнату.
- Награда контракта `CLEAR STATIC STORM` навсегда отключает источник шторма от STATIC CORE в текущем забеге, сохраняя урон и удачу.
