# v2.1.214 — Offline Folder Launcher

## Исправление запуска из папки

- Добавлен `PLAY_OFFLINE.bat`: одиночная игра теперь запускается двойным кликом прямо из готовой папки.
- Лаунчер использует только встроенный PowerShell и не требует игрового сервера, интернета, Node.js или Python.
- Локальный файловый запуск автоматически выбирает свободный порт и открывает игру в браузере.
- Окно лаунчера должно оставаться открытым во время игры; его закрытие останавливает только локальную раздачу файлов.
- При ошибочном прямом открытии `index.html` меню теперь явно просит запустить `PLAY_OFFLINE.bat`, а не оставляет неработающие кнопки.
- Сетевая игра остаётся отдельной: создание сектора и вход по коду по-прежнему требуют сигнального сервера.

## Проверки

- Лаунчер проверен при выключенном сигнальном сервере.
- Проверены загрузка всех игровых модулей, запуск SOLO кнопкой и отсутствие ошибок в браузере.
- Добавлен отдельный регрессионный тест комплектации офлайн-лаунчера.
