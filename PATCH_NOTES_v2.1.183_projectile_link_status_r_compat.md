# v2.1.183 — Projectile Link / Signal Spike / R compatibility

## Связь снарядов

- Базовая «Связь снарядов» теперь передаёт дальше только урон.
- Огонь, холод, коррозия и другие оружейные статусы больше не распространяются по связи автоматически.
- В WPN-сундук добавлен разовый «Статусный канал связи».
- Он может появиться после получения самой связи, даже если оружейных статусов пока нет.
- После выбора связь переносит все текущие и будущие оружейные статусы на следующие цели.
- Повторно это улучшение не выпадает.

## SIGNAL SPIKE

- Каждый уровень заметнее увеличивает дальность установки.
- Каждый уровень заметнее увеличивает радиус зоны.
- Предпросмотр и реальная установка используют одинаковые значения.
- Короткие описания обновлены на русском и английском.

## Совместимость R

- `TARGET LOCK` больше не предлагается Живому казино и Контролёру: принудительный захват прицела конфликтовал с их ручными многоканальными целями.
- Для обычного героя `TARGET LOCK` сохранён.
- Остальные рабочие R-награды не ограничивались без причины.

## Уже исправленное ранее

- `VOID CUT` уже работает как двухэтапный построитель звеньев: первое Q ставит начало, следующие Q прокладывают луч. Повторно механика не переделывалась.
- Отдельный канал статусов дронов сохранён без изменений.
- `FIELD SNAP` остаётся чистой control/utility-активкой без собственного урона.

## Проверка

- Проверены пассивное действие на текущие/будущие статусы и запрет повторного выпадения.
- Проверена блокировка автоматического переноса статусов базовой связью.
- Проверены рост дальности/радиуса SIGNAL SPIKE и совпадение формул.
- Проверены ограничения R по героям.
- Прогнаны проверки v2.1.181–v2.1.183, синтаксис JS и тексты RU/EN.
